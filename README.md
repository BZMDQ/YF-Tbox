# 研发工具箱 0.8.47

本版基于本机 0.8.46，保留已有 PIC24、W78、STM32 和 D133 烧录流程。

- 固件升级只选择完整系统 OTA；取消独立 `.fapp`、`.fappb` 更新入口。STM32 使用 `.ota.bin`，D133 使用 CPIO 与签名。
- 物理网卡查询提前在后台进行，成功结果缓存 30 秒；并发连接共享一次查询。绑定地址失效后重新查询，保留公司跨网段的物理网卡选择规则。
- TCP 建连和 Key 认证分别限时、可取消。只有无副作用的建连和认证最多尝试两次；设备拒绝认证、CRC 或协议错误直接报错。
- 启用 TCP_NODELAY 与 TCP 保活。设备信息页“保持信息连接”仅对只读监听自动重连，点击停止可退出；OTA 和烧录不会自动重放。
- 读取完成主动释放连接时显示“连接已释放”，不把正常释放显示成掉线故障。

## 文件

`Source` 为可编辑源码，`程序` 为本机完整 onedir 程序，`构建记录` 为测试与构建结果。直接运行程序目录中的 `ResearchToolbox_0.8.47.exe`，不可只复制 EXE。

GitHub Release 提供原生手动安装 EXE，不再发布额外 ZIP。公共安装程序包含完整应用运行文件及源码，不捆绑厂商 CubeProgrammer 或 ST-LINK 驱动；升级时保留安装目录中已有的厂商工具。全新电脑需另行安装厂商工具后在界面选择其路径。

工具箱不提供自动更新。安装前请退出旧工具箱，保留用户配置及密钥，不把私有配置上传到公共仓库。

主机测试与打包界面检查不代表开发板、Wi-Fi 或 OTA 现场验证。本次未复位、未烧录开发板。
