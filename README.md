# 研发工具箱 0.8.48

配套 STM32F750 系统1.4.37，使用16KiB分片、窗口2，在协议协商成功后保持最多两个分片在途。旧固件不支持时继续兼容窗口1，禁止仅改日志伪装窗口2。

保留0.8.47物理网卡缓存、可取消建连、TCP保活、只读信息连接自动重连，以及统一系统OTA和D133独立协议。无独立App更新入口，无工具箱自动更新。

主机测试、打包及隔离安装检查不代表实板Wi-Fi/OTA验证，本次不复位、不烧录开发板。
