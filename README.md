# F750 1.4.46 / D133 1.0.168 USB CDC 配套控制

F750 PA11/PA12 为 USB FS Host，D133 烧录口运行 CDC Device，由板上固定5V供电。设备互联页新增 USB D133 控制，支持 CS000／CS001 二次确认切换、EXIT 和 TEST0–TEST8；返回/取消不重放命令。USB控制和D133本地/网络OTA共用预约，避免切屏重启打断升级。

F750 保持裸机、BOOT1.0.16、系统OTA窗口1和原Wi-Fi/弱AP策略；48MHz USB时钟只在应用最早启动、外设与QSPI未启用时准备，CPU仍216MHz。IRQ安全门驻SRAM，实际Host/HCD代码驻QSPI；最终链接已检查主机栈未被LTO消除。D133基于当前定制1.0.167 SDK，固定USB0 Device FS、64字节CDC端点。

已完成生产C定向模型、独立审阅、两端完整构建、HEX/CPIO与RSA签名验证，尚未实板枚举、供电余量、插拔或屏幕画面验收。配套OTA、工厂HEX/IMG和源码分类保存在项目本地下载目录，不额外生成ZIP。工具箱继续0.8.50。
