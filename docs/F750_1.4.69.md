# F750 1.4.69

发布日期：2026-11-20。内部 BOOT 保持 1.0.17。

- 降低 USB-D133、Network、Programmer 任务的空闲轮询频率；USART1 收到数据时可及时唤醒网络任务。保留传输和烧录期间的处理节奏。
- 任务管理器定时刷新数据区，减少整页重绘。
- 修复空闲 W78 流程提前取消校时与会议日历 HTTP 请求的问题。出站 HTTP 可在关闭本地 TCP 服务时自行初始化，工具箱空闲连接不会阻止自动校时。

交付文件为 `STM32F750_1.4.69.ota.bin` 和 `FactoryOTA_1.4.69.hex`。本地下载目录已更新；此仓库仅同步版本说明。

Keil5 源码目标与系统镜像构建通过，已核对 OTA 与完整 HEX 的系统镜像一致。同步恢复和 CPU 占用降幅待实板确认。
